# WeatherData Java Project

# Description
This is a simple Java program that represents weather information using a class named `WeatherData`.  
It checks temperature and humidity values and generates alerts based on predefined conditions.

---

# Features
- Stores temperature and humidity
- Uses constructor to initialize values
- Generates alerts:
  -  High Temperature Alert (temperature > 40)
  -  Low Temperature Alert (temperature < 10)
  -  High Humidity Alert (humidity > 80)
  -  Weather is Normal (if no extreme condition)

---

# Technologies Used
- Java (Core Java)
- OOP Concepts (Class, Object, Constructor, Method)
